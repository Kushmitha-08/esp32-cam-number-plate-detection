# Number Plate Detection Using ESP32-CAM

## Project Overview
An IoT-based project designed to capture vehicle images using ESP32-CAM and explore number plate detection using image processing and Optical Character Recognition (OCR).

## Objectives
- Capture vehicle images using ESP32-CAM.
- Process images to identify vehicle number plates.
- Explore OCR for extracting text from number plates.
- Demonstrate a camera-based vehicle identification workflow.

## Technologies Used
- ESP32-CAM
- Python
- OpenCV
- Tesseract OCR
- IoT

## Working Principle
1. Capture a vehicle image using ESP32-CAM.
2. Process the image using computer vision techniques.
3. Identify the number plate region when detectable.
4. Apply OCR to attempt to extract the characters from the plate.

## Expected Output
- Captured vehicle images.
- Image processing for number plate localization.
- Extracted plate text when the image quality and OCR recognition permit.
